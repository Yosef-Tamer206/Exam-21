# Cozy Corner - Furniture Store (Team Project)

A furniture store landing page built as a team project: hero, selected products, team members and contact.

**Live demo:** https://yosef-tamer206.github.io/Exam-21/

![Exam-21 screenshot](docs/screenshot.png)

## Features

- Hero section for the store brand
- Selected products showcase
- Team members section
- Contact section
- Responsive layout

## Tech Stack

- HTML5
- CSS3
- Font Awesome icons

## Run Locally

```bash
git clone https://github.com/Yosef-Tamer206/Exam-21.git
cd Exam-21
```

Open `index.html` in a browser.

## Notes

- Static front-end page; product and contact details are sample content.
